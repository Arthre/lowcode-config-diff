# LowCode Config Diff

纯前端的**可编辑双栏文本合并工作台**。

对照 **参考** 与 **结果** 两份配置文本，按 CodeMirror 差异块把左侧写入右侧，再复制或下载右栏。全程在浏览器中完成，不上传配置。V0.1 的「每叶 TEST | PROD」选边主路径已退出。

## 能做什么

1. **导入或粘贴**：在 Merge 栏头点选 / 粘贴全文 / 清空，或把 JSON 拖到对应整栏（合法 object/array 根则格式化一次）；空栏有居中提醒与虚线落区
2. **打开即对照**：满高可编辑 MergeView；**无**「开始 Diff」门禁
3. **按块采纳**：中间 `→` 将参考差异块写入结果；采纳单位是 CM 差异块，不是 JSON path / 叶子选边
4. **块导航**：上一条 / 下一条（绕回），页眉显示当前块 / 总数
5. **复制或下载右栏**：只导出结果侧；可下载 `config.json` 或压缩为 `config.min.json`；非法 JSON 会提示，但仍可导出
6. **查找**：Ctrl+F 打开栏头下方的查找条，不进入编辑器
7. **冲突缩略图**：右侧窄轨只标差异行位置，点击或拖动跳转

## 使用说明

1. 为左栏（参考）与右栏（结果）分别导入或粘贴 JSON 文本
2. 在满高双栏 Merge 中对照、直接编辑；需要时点 `→` 把参考块写入结果
3. 页眉「复制」或「下载」只出右栏结果；下载按钮可选择压缩

左右始终并排；窄屏宿主可横滑，**不会**改成上下堆叠。界面支持亮色 / 暗色主题。刷新后不恢复会话内容；配置默认只在本地处理。

## 技术栈与备用引擎

- Vue 3 + TypeScript + Vite + Pinia + CodeMirror 6（`@codemirror/merge`）；包管理器 pnpm
- Core 仍含 `diffConfig` / `mergeConfig`；**现行 UI 不调用**（导入校验 / 格式化与引擎单测仍用 Core）

文档真相源见 [PRODUCT.md](./PRODUCT.md) 与 [`.docs/`](./.docs/)。

## 不在范围内

- 后端保存、云端同步、登录权限
- 对接低代码平台发布或 Git
- 双模式（结构选边 ↔ 文本合并）切换、自研结构 merge 引擎接回主路径
- 忽略键序 / 空白的「语义相等」diff
