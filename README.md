# Diff 合并工具

纯前端的低代码 JSON **对照合并**工作台。

左栏是**参考配置**，右栏是**目标配置**。导入两侧文本后即可满高对照、直接编辑；中间 `→` 把参考侧的差异块写入目标配置，再复制或导出右栏。全程在浏览器本地完成，**不上传**配置。

## 能做什么

- 导入、粘贴或拖入两侧 JSON，打开即对照、直接编辑
- 中间 `→` 按差异块把参考写入目标配置
- 差异导航、仅显示差异、缩略轨、查找与格式化
- 复制或导出右栏；本地处理，支持亮 / 暗主题

## 使用说明

1. 为左栏（参考）与右栏（目标）分别导入、粘贴或拖入 JSON
2. 在双栏中对照、直接改目标配置；需要时点 `→` 采纳参考块
3. 用页眉「复制」或「导出」取出右栏

## 本地运行

需要 **Node ≥ 20.19** 与 **pnpm ≥ 10**（只用 pnpm）。

```bash
pnpm install
pnpm dev
```

| 命令            | 用途                |
| --------------- | ------------------- |
| `pnpm dev`      | 开发服务器          |
| `pnpm test:run` | 单测                |
| `pnpm build`    | 类型检查 + 生产构建 |

## 技术栈

Vue 3、TypeScript、Vite、Pinia、CodeMirror 6（`@codemirror/merge`）、UnoCSS。

`src/core/` 仍保留 `diffConfig` / `mergeConfig` 等纯函数，供导入校验、格式化与单测使用；**现行界面按文本差异合并，不走结构选边**。

更细的产品口径见 [PRODUCT.md](./PRODUCT.md)，模块说明见 [`.docs/`](./.docs/)。
