## 背景与目标

**现行：** `←` 写回参考已从中间槽暂时移除，仅保留 `→`。页眉视口锚点仍有效。

---

## 需求变更

### + 新增

- 页眉差异计数改为带当前锚点：有块时为「N / M 个差异块」（N 从 1 计）；无块时仍为「0 个差异块」。
- 当前块下标随 **Merge 视口滚动** 更新：取与视口重叠的最上一块；视口落在两块之间的空白时取已经过的一块。上一条 / 下一条滚入视口后同样更新。

### ~ 修改

- 中间槽默认只渲染 `→`。用户点过一次 `→` 后，其余仍存在的差异块在 `→` 下方出现 `←`。MergeView 会复用旧控件节点，解锁后必须给已在 DOM 里的槽补上 `←`，不能只靠新建 `renderRevertControl`。
- `←` 语义不变：把该结果块写回参考。本次采纳掉的那一块两侧已对齐，不再显示控件。
- 重新导入或清空任一侧时，写回解锁复位为只显示 `→`。

### 非目标

- 不在已对齐行上残留「幽灵 ←」
- 不改导出只出右栏、不改 Core

---

## 验收清单

1. 初次对照每个差异块只有 `→`
2. 点一次 `→` 后，剩下的差异块（含库复用的旧节点）出现 `←`
3. 滚动视口或上一条 / 下一条时页眉为「当前 / 总数 个差异块」，随视口最上重叠块变化
4. `pnpm lint` / `pnpm test:run` / `pnpm build` 通过
