## 背景与目标

空栏只有行号 1，拖放必须落到 gutter 才导入；中间只有 `→`。本变更：分栏空态提醒与落区、按横坐标判栏拖放、`←` 把结果该块写回参考（撤回结果修改）。复制/下载仍只认右栏。

---

## 需求变更

### + 新增

- 该侧文档为空时，在 Merge 宿主上叠空态层：参考「还没有参考配置」、结果「还没有结果配置」；说明「把 JSON 拖到此栏，或用栏头上传 / 粘贴」；上传图标；层内「选择文件」打开该侧文件选择器。
- `←`：将结果侧该差异块写回参考（b-to-a）。`aria-label`：「将此结果差异写回参考」。不是第二导出路径。

### ~ 修改

- 拖放按 `clientX` 相对左右编辑器矩形判栏，空栏任意位置可导入。
- `→` 仍为采纳参考写入结果（a-to-b）。
- 空栏编辑器 `min-height: 100%`；空态虚线落区；拖入中 accent 描边。
- 双侧都空时不渲染差异缩略图。
- 总览中间区与「不做」去掉 `←` 禁令。

### 非目标

- 不换成独立 Dropzone 页、不插画、无 01/02/03
- 不改 Core `diffConfig` / `mergeConfig`、不改导出只出右栏
- 不启用 Unified、不自绘可拖宽第三列

---

## 验收清单

1. 空栏任意位置拖入即可导入对应侧；虚线落区与居中提醒可见；只空一侧时仅该侧有提醒
2. 双侧都空无缩略图；有一侧内容则缩略图在
3. `→` 写右、`←` 写左；右栏 Undo 只撤结果侧
4. `pnpm lint` / `pnpm test:run` / `pnpm build` 通过
