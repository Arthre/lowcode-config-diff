# 工作台 Operate 扫读优化

**日期：** 2026-08-20  
**状态：** 已落地（第一阶段：文案、工具栏、空态、点阵）  
**来源：** 用户提供的《配置差异合并工具 · 界面优化建议》第一阶段

## 背景

空态卡片与页眉控件同级并列，差异数量不够醒目；「上传 / 删除 / 下载 / 结果」与本地合并任务的语义不完全对齐。

## 需求变更

### 新增

- 页眉工具栏分为三簇：隐私（与主题同排）、差异状态 + 导航、搜索 / 复制 / 导出
- 无差异时页眉显示「无差异」；有差异时显示「当前 / 总数 个差异」（有锚点）或「N 个差异」
- 空栏提示改为轻量文案：拖入或粘贴、支持 `.json`、选择文件；整栏仍是落区

### 修改

- 右栏展示名：结果 → **目标配置**（查找条短称为「目标」）
- 左栏展示名：参考 → **参考配置**
- 栏头：选择文件 → **导入**；清空保持；粘贴全文仍叫 **粘贴**（剪贴板按钮实际是整栏粘贴，不改成「复制」以免名实不符）
- 页眉：下载 → **导出**；上一条 / 下一条 → **上一个差异 / 下一个差异**
- 隐私文案：`本地处理 · 不上传` → `本地处理`，悬停说明不出域
- 背景点阵降到约原来的 40%

### 移除

- 空态大卡片标题与「栏头上传 / 粘贴」冗长说明

## 本切片不做

- 中间双向 Diff Gutter / 恢复 `←`（产品仍为仅 `→`）
- 新增 / 删除 / 修改分类统计
- 差异列表与批量勾选应用
- 搜索 JSON Key/Value 分模式（Ctrl+F 已有）
