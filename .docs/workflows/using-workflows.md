# 工作流优先（Using Workflows）

> **触发时机**：开始任何对话、任务或响应之前。 **借鉴来源**：[Superpowers `using-superpowers`](https://github.com/obra/superpowers/blob/main/skills/using-superpowers/SKILL.md)，已适配本项目 `.docs/workflows/` 体系。

## 铁律

**在做出任何响应或行动之前** — 包括澄清问题、探索代码库、读取文件 — 必须先检查是否有相关工作流适用。

如果工作流适用，**必须使用**，不能用"这次简单"来跳过。

```
如果某项工作流有 1% 的可能性适用 → 必须先读它
```

## 工作流优先级

多个工作流同时适用时，**流程类工作流优先** — 它们决定怎么做，领域工作流决定做什么：

| 用户意图                   | 优先工作流                                                                                    |
| -------------------------- | --------------------------------------------------------------------------------------------- |
| "做个 X" / 新功能 / 改行为 | [需求设计](./brainstorming.md) → [编写计划](./writing-plans.md)                               |
| "修这个 bug"               | [系统化调试](./debugging.md) → [TDD](./tdd.md)                                                |
| 有计划要执行               | [子代理驱动开发](./subagent-driven-development.md)（推荐）或 [执行计划](./executing-plans.md) |
| 声称完成                   | [完成验证](./verification.md)                                                                 |
| 查看/修改代码              | [CodeGraph](./codegraph.md)                                                                   |

**进入计划模式前**：如果还没做过需求设计，先走 [需求设计](./brainstorming.md)。

## 使用方式

1. 识别适用工作流
2. 宣布："使用 [工作流名] 来 [目的]"
3. 严格按工作流执行；如有检查清单，为每项创建任务跟踪
4. 工作流与 `AGENTS.md` 冲突时，以 `AGENTS.md` 和用户的明确指令为准

## 危险信号 — 你在合理化跳过工作流

| 想法               | 现实                           |
| ------------------ | ------------------------------ |
| "这只是个简单问题" | 问题也是任务，先查工作流       |
| "我需要更多上下文" | 工作流告诉你**如何**获取上下文 |
| "先探索一下代码库" | 工作流规定探索方式，先查       |
| "我记得这个工作流" | 工作流会演进，读当前版本       |
| "工作流太重了"     | 简单的事也会变复杂，用工作流   |
| "我懂这个概念"     | 懂概念 ≠ 按工作流执行          |

## 子代理豁免

如果你是被派发来执行特定任务的子代理，忽略本工作流，直接执行分配的任务。

## 与上游方法论的关系

本项目将 [Superpowers](https://github.com/obra/superpowers) 的方法论本地化到 `.docs/workflows/`，并将 [ponytail](https://github.com/DietrichGebert/ponytail) 的实现层决策阶梯吸收进 [代码简化](./simplification.md)（不引入其插件命令与强度档位），同时叠加 CodeGraph、需求 Delta、模块活文档等项目约定。外部插件可作为补充参考，但**以本项目 `.docs/` 文档为准**。
