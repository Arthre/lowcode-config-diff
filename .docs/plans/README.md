# 实施计划（Plans）

存放每次变更的**可执行任务清单**，遵循 TDD 细粒度步骤。

## 命名

```
YYYY-MM-DD-<主题>.md          ← 进行中
archive/YYYY-MM-DD-<主题>.md  ← 已完成归档
```

## 何时创建

用户确认 `.docs/specs/` 设计文档后，编码之前编写。

## 文档结构

见 [编写计划](../workflows/writing-plans.md) 与 [变更生命周期](../workflows/change-lifecycle.md)。

## 状态流转

`待执行` → `执行中` → `已完成`（验证通过后移至 `archive/`）
