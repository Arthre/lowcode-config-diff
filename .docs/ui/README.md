# UI 模块

前端视图与组件层。编辑器与页面副作用可依赖 Vue；**不得**把 Vue / DOM 引入 `src/core/*`。

## 设计权威

- 产品真相：[PRODUCT.md](../../PRODUCT.md)
- 视觉系统：[DESIGN.md](../../DESIGN.md)（冷灰画布 + 青绿强调；亮/暗 token 落地于 `src/styles/tokens.scss`；手动主题 + View Transition 圆形揭示）

## 样式目录约定

- 入口：`src/styles/index.scss`（`main.ts` 只引这一处；全局样式统一 **SCSS**）
- 新颜色 / 圆角 / 阴影 → `tokens.scss`（亮暗成对）
- 跨组件复用的 `.ui-*` → `primitives.scss` / `semantic.scss` / `layout.scss`
- 某一功能多组件复用 → `styles/features/<name>.scss`，并在 `index.scss` 末尾 `@use`
- 仅单个组件使用 → 该组件 `<style lang="scss" scoped>`，不进 `src/styles`
- 依赖：开发依赖 `sass`（Vite 原生编译 SCSS）

## 主题

- 切换：`ThemeToggle` → `useThemeToggle`（VueUse `useDark`，键 `lcd-color-scheme`）
- 暗色选择器：`html.dark`（`index.html` FOUC 脚本与之对齐）
- 动画：亮→暗亮色圆形*收回*、暗→亮亮色圆形*进入*（约 340ms，CSS 首帧驱动 + 暗色过渡底，抑白闪）；无 API / 减少动效时瞬时切换
- 页眉：全宽扁平 chrome（非面板）；工作区：满高双栏 Merge（`layout.scss` 单列 flex，Merge 吃剩余高度）
- 页眉工具：单行 chrome——品牌 | 差异徽章（无差异 / `差异 n / m`）与新增 / 删除 / 修改 chips（只读）| 成对导航「上一个 / 下一个」（`aria-label` 仍为「上一个差异 / 下一个差异」；仍遍历全部文本块，不受目录类型筛选影响；上一个描边、下一个 soft，紧凑 padding，按下轻位移；`prefers-reduced-motion` 时关闭位移）|「仅显示差异」为页眉 `UiSwitch`（折叠编辑器未改行，不是目录筛选）| 本地处理、`ThemeToggle`、查找（Ctrl+F）、复制、导出菜单（含压缩）。字段/配置项计数不在页眉，在目录顶栏。目录顶栏有可见「筛选」标签 + 全部/新增/删除/修改 chips
- 单测：`src/composables/useThemeToggle.test.ts`（存储键与揭示半径）

### 现行主路径

打开即对照：满高可编辑 MergeView，导入收在栏头。无「开始 Diff」门禁。复制/导出只出右栏（空栏导出只提示、不下载；非法 JSON 仍导出原文）。刷新不恢复（store 无 persist）。

- `TwoWayMergeEditor`：左参考配置、右目标配置；两枚胶囊栏头导入/粘贴全文/清空（宽度对齐左右编辑器），整栏拖入走 `importSide`（合法则格式化一次；编辑器拦截 Files drop，避免 CodeMirror 按光标插入与导入竞态）；空栏 Lottie 提示居中（选择文件 / 粘贴全文 / 双侧皆空时可填入示例对；dragover 期间仅被拖入的那一栏从动作末帧倒放到 0）；编辑器内 Ctrl+V 仍是光标插入、不格式化；`→` 把参考块写入目标配置（`←` 暂时下线；按类型着色，当前锚点块可辨）；按行 diff；主列 `two-way-merge-body` = 编辑器画框 \| 缩略轨（同高）；目录在缩略轨右侧为推开式抽屉（默认可收起，页眉图标开关；列表独立滚动；可解析 JSON 时按配置项分层，一级为结构根、数组下标折在其下，顶栏可见「筛选」+ 类型 chips，组/字段单行符号树、默认不展示 `L{n}`），否则扁平块预览；缩略色带与 Merge 滚动共用对齐像素（视口中心跟文档进度；resize / 折叠 / 抽屉列宽落地后重测，滚动不重算）；左右横向滚动同步；快拖结束、目录跳转与抽屉开关后对左右 View `requestMeasure` 再同步；Ctrl+F 打开主列内查找条；上一个/下一个按视口与块像素带重叠锚点步进并绕回（仍遍历全部文本块；滚动不重测每块 `lineBlockAt`）；页眉当前块随视口滚动；目录列表不跟编辑器滚动对齐或高亮；文档或块数变化时 `chunks` 带上类型构成与字段摘要，滚动不重分类、不重算分组；layout 时目录偏移与行号对每侧文档至多扫描一次（`jsonPathOffsets` + 换行索引），滚动不重扫；「仅显示差异」开时 `MergeView.reconfigure({ collapseUnchanged })`，默认关
- 导出菜单：`config.json` 或压缩为 `config.min.json`；空栏提示「目标配置为空，无法导出」且不下载；非法 JSON 仍导出原文并以警告提示；复制失败可关闭
- Core `diffConfig` / `mergeConfig` 仍在源码，**UI 不调用**

界面文案、错误提示与代码注释使用**简体中文**。

## 工作台布局

- 视口高：`.ui-page` `100svh` + overflow hidden；`.ui-workspace` 纵向 flex，Merge `flex: 1; min-height: 0`；目录列独立 `overflow-y: auto`，不滚整页
- 窄屏：Merge 仍左右并排，宿主可横滑；禁止把 `.cm-mergeViewEditors` 改成 column
